# 🏥 Chikitsak AI  
AI-Powered Medical Assistance Platform  

Chikitsak AI is an intelligent healthcare assistant built during a hackathon, where our team secured **6th position**. The platform provides preliminary diagnosis and medical guidance based on user-reported symptoms using machine learning models and rule-based triaging logic.

---

## 🚀 Problem Statement

Access to immediate medical guidance is limited in many regions. Users often struggle to determine whether symptoms require urgent care or basic treatment.  

Chikitsak AI aims to:
- Provide quick preliminary diagnosis
- Classify risk levels
- Suggest next steps (self-care / doctor consultation / emergency)

---

## 🧠 Features

- 🔍 Symptom-based AI prediction
- ⚡ Real-time REST API integration
- 🩺 Risk-level classification (Low / Moderate / High)
- 📊 Structured medical response generation
- 📱 Responsive UI built with React + TypeScript
- 🚀 Scalable backend architecture

## ⚙️ Architecture Overview

1. User enters symptoms in the frontend.
2. React frontend sends request to backend REST API.
3. Backend processes request and forwards data to ML model.
4. ML model returns prediction + risk classification.
5. Backend formats response and sends structured medical guidance.
6. Frontend displays diagnosis and recommended action.
